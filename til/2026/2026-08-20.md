## What I learned / re-grounded on

- MCP's real value isn't the wire format, it's the **standardization of the glue**:
  write a tool server once, use it from any MCP-capable host. N custom adapters → 1
  contract.
- The safety boundary is the part people skip: MCP standardizes *connection*, not
  *authorization*. The host still has to validate every call and treat server output
  as **untrusted data**, never as instructions. That's the prompt-injection line.
- Mapped out the broader stack I want to cover beyond agents: inference (vLLM, Groq,
