# RSS/Atom feeds for the daily digest — the "industry pulse" layer.
#
# One URL per line. Blank lines and lines starting with # are ignored; an inline
# "# note" after a URL is fine (only the first token is used). Dead or moved feeds
# are skipped automatically on fetch, so it's safe to keep optimistic entries.
#
# ORDER MATTERS. digest.py keeps the newest few items per feed and caps the total,
# walking this file top-down. The cloud post-routine's sandbox blocks egress to almost
# everything EXCEPT raw.githubusercontent.com, so the reliably-reachable MIRRORS are
# listed FIRST — they are what keeps the digest current from inside the sandbox. The
# open-network sources (arXiv is handled in code; vendor blogs, HN, releases below)
# enrich the digest when the script runs with open internet, and are simply skipped
# when the proxy blocks them.

# ── reachable-in-sandbox mirrors (raw.githubusercontent.com, rebuilt daily) ──
